# 美国国债风险溢价预测与多因子择时

本项目构建了一个美国国债多因子收益预测与均值–方差择时框架：利用收益率曲线、宏观经济、价格趋势和投资者情绪，预测 2–5 年期零息国债未来一年的平均超额收益，再将预测信号转换为相对于 1 年期国债的风险敞口。项目同时比较线性回归、LASSO、随机森林和梯度提升树，并检验不同样本、参数、信息滞后和组合构造方式。

这是基于相关文献的课程研究实现。**当前结果属于原研究设定下的历史递归估计，包含尚未解决的前视与收益计量问题，不能视为严格实时回测或可交易业绩。** 下文说明计算方法、重新运行的结果及其适用边界。

## 1. 策略如何构建

研究对象是美国国债期限风险溢价。每个月形成一次预测，按预测的风险溢价大小调整 2、3、4、5 年期零息国债的平均风险敞口。正权重表示承担期限风险，负权重表示反向敞口；1 年期国债收益率用于构造收益基准。这里的 EH 是“扩展历史均值”预测基准的代码名称，优于它本身不构成对预期假说的完整检验。

计算流程如下：

```text
零息债券价格 ──→ 收益率 / 远期利率 / 远期利差 / 价格趋势 ─┐
宏观月度面板 ──→ 平稳化 → 标准化 → PCA / 原始变量机器学习 ├→ 一年期超额收益预测
投资者情绪   ──→ 情绪水平 / 平方 / 12 个月变化           ─┘          ↓
                                                    均值–方差权重与研究统计
```

主设定从 1990 年 1 月开始递归预测；回归至少需要 120 个有效训练观测。PCA 的均值、标准差和载荷固定在 1964–1989 年估计，之后仅投影新观测；回归系数按预测月份更新。注意，当前训练条件只是“行日期早于预测日”，尚未按一年期标签的实际兑现时间隔离训练集。

### 预测目标与基础变量

设 $P_t^{(n)}$ 为面值 100 的 $n$ 年期零息国债价格，代码统一使用百分数单位：

$$
\ell_t^{(n)}=100\log(P_t^{(n)}/100),\qquad
y_t^{(n)}=-\ell_t^{(n)}/n.
$$

一年期远期利率和远期利差为：

$$
f_t^{(1)}=y_t^{(1)},\qquad
f_t^{(n)}=\ell_t^{(n-1)}-\ell_t^{(n)},\qquad
fs_t^{(n)}=f_t^{(n)}-y_t^{(1)}.
$$

在 $t$ 买入 $n$ 年期债券，持有一年后作为 $n-1$ 年期债券卖出，得到一年期对数超额收益：

$$
rx_t^{(n)}=\ell_{t+12}^{(n-1)}-\ell_t^{(n)}-y_t^{(1)},\qquad
\overline{rx}_t=\frac{1}{4}\sum_{n=2}^{5}rx_t^{(n)}.
$$

所有收益标签记录在**买入月份 $t$**，需要未来 12 个月的价格才能计算。相邻月份的标签高度重叠。

## 2. 使用了哪些因子，如何计算

| 模型 / 因子 | 计算方法 | 捕捉的信息 |
| --- | --- | --- |
| **FB：远期利差** | 对 $fs_t^{(2)},\ldots,fs_t^{(5)}$ 取平均，再用 OLS 预测 $\overline{rx}_t$；另有逐期限版本 | 曲线蕴含的期限补偿 |
| **CP：远期利率组合** | 用 $f_t^{(1)},\ldots,f_t^{(5)}$ 回归平均超额收益，拟合值作为单一 CP 信号，再用于第二阶段回归；系数递归估计 | 整条曲线中与未来收益相关的信息；不强制系数呈帐篷形 |
| **LN：宏观主成分组合** | 将 132 个原始宏观序列按变量性质变换、标准化，提取 8 个主成分；基准规格使用 $F_1,F_1^3,F_2,F_3,F_4,F_8$，先形成收益拟合值，再作第二阶段回归 | 经济活动、就业、通胀、货币和金融条件的共同变化 |
| **LN_LASSO** | 在 $F_1,\ldots,F_8,F_1^3$ 中逐期用 LassoCV 选变量，再以选中变量进行两阶段 OLS | 检查固定宏观因子子集对结果的影响；只处理变量选择，未消除其他前视问题 |
| **TI：价格趋势** | 各期限 $TI_t^{(n)}=\ell_t^{(n)}-\frac{1}{12}\sum_{j=0}^{11}\ell_{t-j}^{(n)}$，取跨期限平均，再进行预测回归 | 债券价格偏离近期趋势的程度 |
| **BW：投资者情绪** | 使用已对宏观变量正交化的 `SENT_ORTH`，构造 $S_t,S_t^2,S_t-S_{t-12}$，递归回归后形成情绪组合信号 | 市场情绪及其非线性、年度变化；不预设一定反转 |
| **CPLN / LNBW 等组合** | 分别构造各模型的一阶段拟合信号，再联合进行二阶段回归；代码还提供 CP+TI、CP+BW、LN+TI、CP+LN+BW | 检查不同信息来源是否互补；并非简单平均所有因子 |
| **LASSO_raw / RF_raw / GBM_raw** | 直接使用变换后的 132 个宏观序列；每期剔除训练期缺失率超过 20% 的变量，以训练期均值填补缺失、训练期尺度标准化，再拟合模型 | 保留 PCA 压缩可能遗漏的变量信息与非线性关系 |
| **RF_pca / GBM_pca** | 直接将 $F_1,\ldots,F_8$ 输入树模型，预测平均超额收益 | 比较特征压缩和模型非线性的作用 |
| **CYC / TREND：周期与残差扩展** | 在初始样本对各期限收益率回归 CPI 同比 $100\log(CPI_t/CPI_{t-12})$ 与失业率；分别对拟合值和残差提取第一主成分 | 本项目的简化周期分解；不是 Cieslak–Povala 原文方法的完整复现 |

宏观变换代码在 [`bond_rp/config.py`](bond_rp/config.py) 中逐变量指定：水平、一阶差分、对数、$100\Delta\log x$ 或 $100\Delta^2\log x$。扩展 FRED-MD 面板读取 CSV 首行的变换码，额外支持二阶差分和增长率变化。标准化与 PCA 只使用各自的拟合窗口。

机器学习设定：LASSO 使用 `LassoCV(cv=5, max_iter=5000)`；RF 使用 100 棵树、最大深度 3；GBM 使用 100 棵树、最大深度 2、学习率 0.05、子采样比例 0.5。树模型固定随机种子 42。这些是本项目采用的配置，不表示已逐项复现原论文的估计程序。

## 3. 如何将预测转换为仓位

基础组合采用截断的均值–方差权重：

$$
w_t=\operatorname{clip}\left(
\frac{\widehat{\overline{rx}}_t/100}{\gamma\widehat{\sigma}_{IS}^{2}},-3,3
\right),\qquad \gamma=5.
$$

$\widehat{\sigma}_{IS}^{2}$ 是买入月份位于 1964–1989 年的 $\overline{rx}/100$ 样本方差。研究统计使用 $e_t=w_t\overline{rx}_t/100$，总收益代理为 $r_t^p=e_t+y_t^{(1)}/100$。效用统计为：

$$
AU=\operatorname{mean}(r^p)-\frac{\gamma}{2}\operatorname{var}(r^p),\qquad
\Delta AU=10{,}000\,[AU_{model}-AU_{EH}].
$$

交易成本按 $|w_t-w_{t-1}|\times0.5/10{,}000$ 扣除，初始仓位设为 0。**0.5 bps 是研究假设，未由实际成交数据校准。** 由于仓位按月形成、收益标签覆盖一年，该扣费结果只用于设定内的敏感性比较，不能解释为真实净收益。

代码还实现了逐期限独立权重、完整协方差与 Ledoit–Wolf 收缩、滚动方差等扩展。完整协方差版本使用评价样本的收益估计协方差，存在前视，因此不作为 README 主结果。滚动方差也需要按标签兑现时间重新对齐。

## 5. 从结果中可以得出什么结论

<!-- BEGIN FINDINGS -->
1. **宏观信息值得进一步研究。** 在本次共同样本上，LN 的预测 R² 为 25.52%，FB 为 12.73%，CP 为 10.06%。固定因子组合和递归 LASSO 版本 （17.74%）的差异说明变量选择会影响结果。
2. **GBM 在当前比较中领先，树模型并非普遍优于线性。** 当前设定中 GBM_raw 的预测 R² 最高，为 35.38%；RF_raw 为 23.83%，LASSO_raw 为 24.59%。这是需要在正确时间对齐后重检的模型排序。
3. **预测改善不等于风险调整收益改善。** LN 的加权一年期超额收益均值为 4.30%，但其收益/波动比为 0.65，EH 为 0.67；杠杆与波动会改变配置效果。
4. **组合信号不保证优于单模型。** LN+BW 的 R² 为 21.90%，CP+LN 为 17.75%；加入更多信号可能同时引入噪声。
5. **宏观模型的预测优势未在扩展设定中保持。** 更换宏观面板并拼接 GSW 后，LN 的 R² 为 -25.62%，LN_LASSO 为 -98.09%，FB 为 7.80%。宏观规格的预测误差高于历史均值基准，不能宣称策略跨样本稳健有效；需要拆分数据源变化与时期变化后重新检验。
<!-- END FINDINGS -->

这些发现支持继续研究债券风险溢价的条件预测和信号配置，但不能直接证明因子具有因果解释力、预期假说被严格拒绝，或某个策略已经具备实盘可行性。

## 6. 已知缺陷与改进方向

1. **一年期标签未按兑现时间隔离。** 当前 `_train_slice` 和 EH 基准使用 `index < t`；但 $rx_s$ 要到 $s+12$ 才可观测。例如 1990 年 1 月不应使用 1989 年 12 月买入后的全年收益训练。应改为仅纳入 $s+12\le t$ 的标签，并按预测日的具体时点决定是否再滞后一月；初始方差估计也需要同样处理。
2. **重叠收益不能直接复利。** 原 `strategy.py` 对每月观测的一年期收益做累计乘积，并据此输出回撤；该路径重复计算持有期，不能作为账户净值或真实最大回撤。README 不展示这种净值图和回撤。下一步应建立真正的月度逐笔持仓收益，或明确模拟 12 个错开建立的年度持仓组合，并处理对数收益向简单收益的转换。
3. **宏观与情绪数据不是历史实时版本。** 固定 PCA 只能避免载荷估计使用后期观测，无法消除修订数据、情绪指数构建和实际发布日期带来的信息偏差。主规格也未统一应用发布滞后；代码中的滞后敏感性分析不能替代实时数据库。
4. **变量选择与交叉验证仍需改进。** LN 固定使用既定的六项因子子集；LN_LASSO 只改善选择步骤。当前 `cv=5` 为普通 K 折，并非按时间前推、且带一年隔离区的验证；标准化还发生在交叉验证划分之前。应使用时间顺序验证，在每个折内完成预处理，并隔离重叠标签。
5. **统计显著性可能高估。** 样本内回归使用 18 阶 Newey–West 标准误，但当前 Clark–West 实现对损失差序列使用普通标准误，未处理重叠标签的序列相关。README 因此不展示其显著性星号；正式推断应改用 HAC 或合适的区块自助法，并处理多模型比较。
6. **组合扩展尚不成熟。** 收缩协方差使用完整评价样本，另有非标准缩放；独立权重与完整协方差版本的组合归一化也需要重新核验。周期/趋势和季度持有期扩展均是简化实现，不能当作原论文方法已验证的证据。
7. **交易约束较简化。** ±3 的杠杆限制和固定单边成本没有覆盖融资、卖空、保证金、换券、冲击成本及期限匹配；也尚未对应到实际可交易的国债或期货合约。
8. **版本、收敛和数据衔接风险。** 原始宏观 LASSO 在本次环境中出现部分收敛告警；旧数据与 GSW 在 2013 年切换，宏观面板也更换了定义。应检验优化收敛、数据版本、拼接断点及真正独立的留出期。
9. **情绪变化量的适用性有疑问。** 本地 Baker–Wurgler 工作簿的说明提醒，这些是低频水平指标，不宜直接用差分度量情绪变化；当前 BW 规格仍加入 12 个月差分，因此只作为探索性特征，应与不含差分的规格对照。

| `GSW_yields.csv` | 仅扩展分析；保留官方说明行及第 10 行表头，读取 `Date`、`SVENY01`–`SVENY05`，取每月最后观测，按 $\ell^{(n)}=-ny^{(n)}$ 转换 | [美联储名义收益率曲线说明](https://www.federalreserve.gov/data/nominal-yield-curve.htm)与[官方 CSV](https://www.federalreserve.gov/data/yield-curve-tables/feds200628.csv)，即 Gürkaynak–Sack–Wright 估计曲线；是模型拟合零息收益率 |
| `2026-04-MD.csv` | 扩展与周期分析；`sasdate` 为日期列，第一条数据行保留变换码；周期部分使用 `CPIAUCSL`、`UNRATE` | [圣路易斯联储 FRED-MD 页面](https://www.stlouisfed.org/research/economists/mccracken/fred-databases)与[2026-04 官方文件](https://www.stlouisfed.org/-/media/project/frbstl/stlouisfed/research/fred-md/monthly/2026-04-md.csv)；保持该版本以便比较 |
| `RFS2009.xls`、`1964to2007.xls` | 仅 `code/replicate_papers.py` 最后的历史数据对照部分需要，不参与主预测因子构造 | [Ludvigson 数据页](https://www.sydneyludvigson.com/data-and-appendixes)中 2009 RFS 与 Factor Analysis 数据入口；保留原工作表结构 |

默认将文件放入项目根目录下的 `GroupProjectData/`，也可用环境变量 `BOND_RP_DATA_DIR` 指定自己的数据目录。基准报告只需前三个文件；完整分析还需 GSW 与 FRED-MD；文献复现对照另外需要最后两个文件。

## 8. 安装与复现

Python **3.11 或以上**。保留 `pyproject.toml` 是为了说明运行所需依赖；不依赖 uv 才能运行。推荐先建立虚拟环境：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[report]'

# 重建本文全部模型比较表和两张图片
python scripts/export_readme_results.py --with-ml --with-extensions --update-readme

# 原研究的全部表格、参数与稳健性检查
python scripts/run_analysis.py

# 三篇基础文献的样本内复现及历史数据对照
python code/replicate_papers.py
```

也可使用 `uv run --extra report scripts/export_readme_results.py --with-ml --with-extensions --update-readme`，或 `uv run scripts/run_analysis.py`。uv 在本地生成的锁文件和环境不属于发布内容。仅想运行较快的基准报告时可省略三个可选开关；这将重新绘制只含基础模型的比较图。

导出脚本将汇总表、逐期预测、输入文件 SHA-256 和依赖版本写入本地 `output/`，两张展示图写入 `assets/`。报告不会自动下载或重新分发原始数据；需要先自行准备上述文件。不同版本的 NumPy / scikit-learn 可能产生细小差异，本次环境见下表。

## 10. 方法参考

核心思路参考 Fama–Bliss (1987)、Cochrane–Piazzesi (2005)、[Ludvigson–Ng (2009)](https://www.nber.org/system/files/working_papers/w11703/w11703.pdf)、Goh 等 (2013)、Laborda–Olmo (2014)，机器学习与组合扩展参考 [Bianchi–Büchner–Tamoni (2021，2020 年在线发表)](https://doi.org/10.1093/rfs/hhaa062)、Gu–Kelly–Xiu (2020)、Gargano–Pettenuzzo–Timmermann (2019)、Thornton–Valente (2012) 和 Cieslak–Povala (2015)。Bianchi 等的研究另有[关于预测信息可得性的勘误](https://doi.org/10.1093/rfs/hhaa098)，阅读和比较时应一并考虑。代码中的简化模型、超参数和评价程序以本 README 的具体描述为准；不将“参考”视为对全部论文结果的完整复现。
